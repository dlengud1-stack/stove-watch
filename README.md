# 스토브워치 무료판

LCK 구단의 이적·재계약, 보도, 찌라시와 예상 로스터를 모읍니다. 유료 API 키, AI 구독, 외부 데이터베이스가 필요하지 않습니다.

## 내 PC에서 실행

ZIP을 풀고 Node.js 22.13 이상이 설치된 Windows에서 `start.cmd`를 실행하세요. 브라우저 주소는 http://localhost:4197 입니다. macOS·Linux에서는 압축을 푼 폴더에서 `npm run build` 후 `npm start`를 실행하세요. 별도 npm 의존성은 없습니다. PC와 수집 프로세스가 켜져 있으면 브라우저를 닫아도 수집합니다. 이전 기록은 `storage/season-2027.json`에 보관하며 재시작 시 이어받습니다. 기존 PC·인터넷을 사용하며 별도 서버 이용료가 없습니다.

## PC를 끄고 무료 공개 사이트로 운영

1. GitHub Free 계정에서 새 **공개 저장소**를 만들고 배포용 ZIP 안의 파일을 저장소 최상위에 커밋합니다. `.github/workflows/free-feed.yml`도 포함하세요. 데이터 파일과 소스가 공개됩니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, 기본 브랜치의 **/(root)**를 선택합니다. 기본 `github.io` 주소를 사용합니다.
3. **Actions → LCK 무료 수집 → Run workflow**를 실행합니다. 작업은 공개 저장소의 표준 Linux 러너에서 실행되고, 저장소 기본 토큰의 콘텐츠 쓰기 권한으로 `stovewatch-feed` 브랜치만 갱신합니다. 별도 액세스 토큰이나 카드 등록은 필요하지 않습니다. 조직 정책이 브랜치 생성을 막으면 첫 갱신이 실패할 수 있습니다.
4. 첫 실행이 성공하면 Pages 주소의 중계실 하단에서 수집 시각과 성공한 경로 수를 확인합니다. 이후 약 10분마다 예약 수집하며 지연될 수 있습니다. 피드는 공개 데이터 브랜치에서 읽으므로 GitHub 캐시로 인한 시차도 생길 수 있습니다.

이 워크플로는 유료 러너, 유료 API, Actions 아티팩트·캐시 및 외부 스토리지를 사용하지 않습니다. 저장소가 비공개이면 수집 작업을 건너뜁니다. 무료 서비스 이용 제한이나 수집 차단이 생기면 수집이 지연되거나 멈추며, 프로그램이 결제를 요청하거나 유료 경로로 전환하지 않습니다. 공개 저장소 예약 작업은 저장소 활동이 60일간 없으면 GitHub에서 꺼질 수 있습니다. 실제 정책은 GitHub 공식 문서에서 확인하세요.

## 수집 채널과 판정

- **구단 공식 유튜브**와 일부 관계자의 공개 영상 피드를 조회합니다. 제목·설명에서 선수와 계약 유형이 뚜렷한 구단 발표를 반영합니다. 영상 음성과 유튜브 커뮤니티 게시물은 자동 판독하지 않습니다.
- **언론·쉽이스포츠**는 공개 RSS, 뉴스 색인, 리크 기사 본문을 확인합니다. 해외 기사는 LCK 팀이나 이번 시즌 LCK를 떠나는 선수와 직접 관련된 발언만 다룹니다.
- **커뮤니티·SNS**는 공개 게시판, 이름 언급 기사, 이적 색인을 확인합니다. 색인에서 찾은 구단 X 링크는 공개 임베드의 작성자와 발표 본문을 대조합니다. 대조할 수 없는 새 링크는 검토 대상으로 남깁니다. 인스타그램·웨이보 계정은 수동 원문 링크이며, X·인스타그램·웨이보의 전체 타임라인을 직접 조회하지 않습니다.
- 로컬에서는 매분 돌아가며 구단 유튜브는 2분, 쉽이스포츠·이적 색인은 4~5분, 언론·인물 언급·게시판은 5~15분을 목표로 확인합니다. GitHub 모드에서는 각 작업이 다음 예약 실행 때 수행됩니다. 호출 제한과 연결 실패는 출처별로 재시도하며 기존 근거를 보존합니다.
- 사이트는 저장된 최신 피드를 60초마다 확인합니다. 미리보기 HTML에는 저장 시점까지의 자료가 들어 있습니다. 소식통 화면에서 직접 수집, 계정 링크, 실패와 마지막 성공을 확인할 수 있습니다.
